# GPCR-PTM

预测并核验 **G 蛋白偶联受体（GPCR）的翻译后修饰（PTM）位点**。输入一个 GPCR（基因名 / UniProt 编号 / 蛋白名），输出**已查证**的 PTM 位点（来自公开数据库）与**预测**的 PTM 位点（规则候选），并对引用的每一篇文献进行核验，确认它是否真的支持对应位点。

提供两种使用方式：**网页界面**（Flask，带进度条）与**命令行**。

---

## 核心原理

### 这属于什么类型的预测？

**基于规则的预测（rule-based），不是机器学习。** 程序不训练数据、不学习参数，而是套用明确、成熟的生物学规则，因此每个结果都有可追溯的理由、完全可复现。

### 已查证位点（L1 / L2）从何而来

已查证位点来自 UniProt、iPTMnet、dbPTM 等数据库，并按**证据强度**分级：

- **实验证据**（文献报道并经 UniProt 人工审读）可信度最高。
- **推断 / 相似性注释**和**高通量单一检出**的可信度较低，并会明确标注（后者标记为"需实验确认"）。

### 预测位点（L3）如何得到

对数据库中尚未记录的修饰，程序分三步预测候选位点：

1. **motif 扫描** —— 在受体序列中搜索公认的共识 motif（磷酸化、N-糖基化 sequon、棕榈酰化）。
2. **膜拓扑过滤** —— 只保留生化上正确的位置：N-糖基化必须在胞外；磷酸化 / 棕榈酰化必须在胞内。这一步滤掉绝大多数假阳性。
3. **保守性与评分** —— 与其他物种的直系同源比对，跨物种保守的位点权重更高，最后统一评分排序。

### 文献逐条核验（每一篇被引用的论文都会核对）

对数据库引用的每个 PMID，程序抓取该文 PubMed 摘要，判断它是否真正支持"**该残基 + 该 PTM 类型**"，返回三种判定：

- **直接** —— 摘要点名了该残基与该修饰。
- **间接** —— 论文确实在讲该蛋白的该修饰，但未点名该残基。
- **不支持** —— 摘要指向的是别的残基或别的蛋白（例如把 Tyr364 的论文挂在 Ser364 位点上）。这类情况往往暴露了数据库的误归属。

### 为什么用规则而不是机器学习？

- **透明** —— 每个位点都带有背后的 motif、区域和证据。
- **可复现** —— 相同输入得到相同输出，无随机性。
- GPCR 的 PTM 共识 motif 已被研究得很充分，显式规则既合适又可解释。

## 使用方法

### 快速开始

**Linux / macOS**

```bash
bash run.sh          # 首次运行自动装好环境并启动网页服务
# 浏览器打开 http://127.0.0.1:8000
```

**Windows** —— 双击 `run.bat`，然后打开 http://127.0.0.1:8000

**手动安装**

```bash
python3 -m venv --without-pip venv
curl -sS https://bootstrap.pypa.io/get-pip.py -o get-pip.py
venv/bin/python get-pip.py
venv/bin/pip install -r requirements.txt
venv/bin/python webapp.py
```

需要 Python 3.8+。

### 网页界面

打开 http://127.0.0.1:8000，输入 GPCR（如 `ADRB2`、`P07550`、`OPRM1`），等待进度条完成。结果会缓存，重复查询秒回。

### 命令行

```bash
python main.py ADRB2
python main.py P07550
python main.py OPRM1 --verbose      # 同时在终端打印每条 PMID 的链接与证据
```

## 输出结果阅读指南

### 三层结构

结果分为三层，建议按这个顺序阅读：

- **L1 · 已查证** —— 有实验报道、带 PMID 的位点。可信度最高，可视为已知修饰。
- **L2 · 有支持** —— 有支持但尚未定论的位点：推断 / 相似性注释、数据库或文献命中、或高通量单一检出（这类会标注"需实验确认"）。可信度较高但未证实。
- **L3 · 预测** —— 数据库中未记录的规则预测候选，是排序后的建议，不是既定事实。

### 文献判定

每条 PMID 标注**直接**（绿）/ **间接**（黄）/ **不支持**（红），用来评估该位点的文献列表有多扎实——"不支持"通常意味着数据库归属有误。

### 分数与置信度

- **分数** —— 0–1 的排序值，**只用于排序，不代表概率**。
- **置信度** —— High / Medium / Low，由 motif 强度 + 保守性决定。

### 输出文件

| 文件 | 用途 |
|------|------|
| `P07550_report.html` | 交互式报告：可折叠位点卡片、可点 PubMed 链接、序列标注 —— 浏览器打开 |
| `P07550_ptm.json` | 结构化数据，便于进一步分析 |
| `P07550_verification.md` | 带链接与摘要证据的文献核验表 |

## 科学依据与注意事项

- 共识 motif 是**必要但不充分**的条件 —— 例如大约只有 30–40% 的 N-糖基化 sequon 实际被占用，磷酸化 motif 的预测力也较弱。分数仅供排序。
- 保守性按基因名匹配直系同源（主要是哺乳动物）计算，保守区域会饱和到接近 1.0。
- "**不支持**"判定指所引论文不支持该残基 + 该 PTM，并不代表位点一定错误。
- 预测属于假设，得出结论前建议用实验（如质谱）验证。

## 数据来源

- **UniProt** —— 序列、拓扑、PTM 注释与证据代码
- **iPTMnet** —— 带 PMID 的文献 PTM 位点
- **dbPTM** —— 可选的离线 PTM 数据集
- **PubMed** —— 逐条核验所用的摘要
